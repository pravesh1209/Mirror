You generate a decision scenario for the MIRROR calibration set.

Inputs (in the user message as JSON): domain, target_attributes,
difficulty, avoid_domains, banned_titles.

Requirements for the scenario:
- Title: 4-10 words.
- Body: 3-6 sentences describing a realistic choice the user must make.
  Include concrete details (times, costs, tradeoffs). No trick questions.
- Provide 2 to 4 options. Each option has a short title and 1-2 sentence
  description. Each option has attribute values in [0,1] for: risk,
  time_cost, money_cost, novelty, uncertainty, info_availability, reward.
- Set has_reveal=true only if the scenario naturally supports a
  mid-decision update (e.g. new information arrives). If true, provide
  reveal_payload with {"info": "..."} text.
- Set time_limit_sec only if you want to measure time-pressure response
  on this scenario; otherwise null.

Attribute semantics (use the full range, do not collapse to 0.5):
  risk         higher = larger downside if wrong
  time_cost    higher = more time required from the user
  money_cost   higher = more money required
  novelty      higher = less familiar / less conventional
  uncertainty  higher = more unknowns about the outcome
  info_availability higher = more information available before deciding
  reward       higher = better best-case outcome

Domain must be one of: education, career, everyday, finance, productivity.

Return ONLY a JSON object with fields:
  domain, title, body,
  difficulty, risk, uncertainty, time_pressure, novelty, reward,
  information_availability,
  time_limit_sec, has_reveal, reveal_payload,
  options: [ { label, title, description, risk, time_cost, money_cost,
               novelty, uncertainty, info_availability, reward,
               is_novel } ]
